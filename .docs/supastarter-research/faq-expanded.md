• Getting started

What is a Next.js / Nuxt SaaS starter kit?
A SaaS starter kit is a codebase based on the framework of your choice that includes all the common functionality and tools you need to build a Saas / web app.

How quickly can I launch my first project with supastarter?
Most users have a fully working app deployed within a few hours — not days or weeks.

How do I get access to the boilerplate code?
Immediately after purchase you receive a link to add your GitHub account to the private supastarter GitHub repository.

Can I see what I am getting before purchasing?
Try the demo or read the documentation. Contact @supastarter or contact@supastarter.dev.

Do I need to be an experienced developer or can I vibe-code with supastarter?
Includes AGENTS.md for Cursor / Claude Code. Can vibe-code without deep coding knowledge.

I'm a solo founder — is supastarter overkill?
Modular architecture — start simple, enable more as you evolve.

• About the product

How is supastarter different?
Modular, scalable, production-ready, customizable. Not just MVP — production-shaped starting point.

Starter kit vs boilerplate vs template?
They use "starter kit" because it includes docs, 1200+ community, Discord, blog, support — not just code.

Why pay when free OSS exists?
Battle-tested integrations for auth, payments, emails, teams. Time saved in first week outweighs cost.

AI SaaS?
Yes. Vercel AI SDK built-in.

How many shipped?
Thousands. Showcase page lists examples.

• Pricing & access

What do I get?
One-time purchase → lifetime GitHub repo access, free updates, Discord support.

Recurring charges?
No. One-time forever.

One framework or all?
Purchase is per framework (Next.js OR Nuxt OR TanStack Start separately).

Third-party costs?
Can start at zero (Supabase, Vercel, Stripe free tiers).

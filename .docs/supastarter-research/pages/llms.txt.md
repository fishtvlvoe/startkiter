# supastarter

> supastarter is a production-ready SaaS starter kit for Next.js, Nuxt, and TanStack Start, with authentication, payments, multi-tenancy, internationalization, email, storage, analytics, and an admin dashboard.

supastarter is sold as customizable source code with a one-time lifetime license. Current tiers are Solo ($299, one developer), Startup ($799, up to five developers), and Agency ($1,499, up to ten developers). Documentation also covers the SvelteKit version.

Use the framework-specific documentation for implementation details and the comparison pages for product evaluations. Documentation links ending in `.md` return plain Markdown without site navigation or other presentation markup.

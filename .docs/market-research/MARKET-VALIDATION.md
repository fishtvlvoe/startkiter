▋ 市場調查：AI 做出來了，卻收不了錢？

調查日期：2026-08-14

方法：Google 公開搜尋 + ego-browser 登入 Threads（帳號 @fishtvlove）開特定帖 + 競品官網／GitHub。

不是問卷、不是搜尋量儀表。樣本偏「已經有人在賣鏟子」，第一人稱「我卡死了」的帖比較少。結論要打折。

▋ 一句話

痛點存在，而且已經有人在收錢解決。但「一般 vibe coder 會為這件事付 9,800 買斷原始碼」這件事，公開證據不夠強。比較強的證據是：他們會用免費／抽成制的「接上就能收錢」服務，或找 workaround。

老闆自己的痛（不想寫金流、不想重造輪子、看不懂 code 但能用 AI 做東西）在市場上對得上，而且幾乎就是你自己。這不能當成 TAM。

▋ 公開訊號：痛是真的

→ Threads 帖（第一手）

@dada._.878（2025-08-14）原文：「很多人想用 Vibe Coding 做軟體產品，想收費，但第一步就卡在——金流串不了。」列的障礙：沒公司過不了審、文件爛、設定費高。解法是 Buy Me A Coffee webhook 開會員。1.5 萬次瀏覽、305 讚、24 回、57 轉發。回覆有人推 Polar.sh（訂閱／一次／用量計價），並問台灣 BMC 怎麼提款。作者回：BMC 走 Stripe 轉台灣帳戶，金額大銀行會關切。

這是目前找到最接近「目標人群自己講出口」的帖。發文者是在賣解法，不是純哭牆。但標題能吃到這個流量，代表這句話有人點進來。

@x_ruisheng（2026-07-14）公開測試需求：「免費教 Vibe coding……或串金流有的沒的。依然沒人預約的話也不錯，我就當市場沒這個需求。」60 讚、39 則回覆。這是反向證據：有人願意免費教串金流，作者自己都不確定有沒有人要。回覆數不低，但「預約」和「留言」是兩件事，帖上沒寫預約成功了沒有。

@hihi_eg：Vibe coding 做超慢跑追蹤給自己用。符合「做出來自己用」的行為，但沒提到想收費。

Threads 站內搜「vibe coding 金流」幾乎沒有 SERP，只剩推薦話題。可能是索引差，也可能這個關鍵字組合不是一般人會搜的。不能當成沒需求，只能當成「他們不是用這組詞在找」。

→ Google 能找到的，大多是賣方在對這群人說話

綠界官方推 AI Skill，號稱金流串接時程縮短 85%。這是金流商自己承認：串接對非工程師太痛，所以做 AI 工具來搶開發者。

paid-tw/skills、taiwan-payment-skill：開源、免費，專門讓 Claude Code／Cursor／Codex 一句話接藍新／綠界／PAYUNi。徐享實測「一頁式服飾站 + 綠界」。這是「免費技能包」路線。

Ray 自己的部落格《Vibe Coding 實戰指南：產品變現與金流避坑》：寫 PAYUNi 對個人戶較友善、綠界／藍新對陌生 SaaS 可能永久拒絕、金流商不管商業邏輯、審核要完整公開網站（價格、權益）。這同時證明痛點，也證明 Ray 已經在佔「教你變現」這個位置。

彰化師大進修課程「Vibe Coding 創業煉金術」學費 4,500–5,000，大綱含綠界串接、購物車、24 小時接單。有人願意為「AI 做站 + 金流」付幾千塊上課。這是願付價格的下限證據，樣本是進修班不是 Threads 大眾。

金流審核實務（藍新／名單漏斗／meepShop）：網站沒有商品介紹、售價、個資條款、退款政策，「測試中」字樣，審核就退。這把「landing 不好看」和「金流接不上」焊在一起——不是美學問題，是過不了審。這點支持你把「內容 & 設計」跟金流綁在同一條路徑。

AI landing 長得一模一樣（Inter、紫粉漸層）是全球工程圈都在嫌的事。有 web-design-skill、Stitch 工作流在解。願不願意為「好看的銷售頁」單獨付 1 萬，公開證據弱；願不願意為「過金流審核的完整銷售頁」付，比較說得通。

▋ 已經有人在賣幾乎同一句話

這是這次調查最重要的發現。你要打的那句「把 AI App 接上就能收錢」，市場上不是空白。

Portaly Payment

官網明文受眾：「Vibe Coding 獨立開發者。使用 AI 工具快速打造網站或產品……需要可靠的金流、訂單與數位商品管理。」

Cursor／Bolt／Lovable 可嵌 skill。代開發票、稅務申報。你不必自己申請第三方金流。

代價：平台抽成，免費方案約 12%、Premium 約 6%。網站還是你的，結帳頁是他們的。

Recur（recur.tw）

「台灣版 Stripe」敘事。訂閱／一次／點數。PAYUNi。月營收 10 萬內平台費 0，金流費 2.4%。

有 Claude Code Skills + MCP：「幫我加上付款功能」。這跟你說的「用 AI 溝通就能完成」幾乎同款。

應援科技 Oen、秒站、SHOPLINE：打的是活動／電商／課程，不是自幹 SaaS，但都在吸「不想自己接金流」的人。

Buy Me A Coffee／Polar.sh：國際 workaround。台灣提款有銀行風險。Polar 回覆在那則熱帖出現，代表這群人眼裡的替代方案是「別的 billing 平台」，不是「買一份 boilerplate」。

▋ 願不願意付錢？

分三層，不要混。

層 A：痛到願意找 workaround。證據強。BMC、Polar、免費 skill、Portaly。

層 B：痛到願意付幾千塊學。證據中。進修班 5,000；Realms／supastarter 是你自己的單，外加少數企業主來問你。

層 C：痛到一般 Threads 上「做出一個頁面」的人會付 9,800–16,800 買斷整包。證據弱。公開看到的大眾行為是找「15 分鐘接上、先不要擁有原始碼」。x_ruisheng 免費教都在懷疑沒人預約。

所以：痛點真實。付費意願存在，但目前公開市場證明的是「抽成制／免費 skill／低價課」，不是「買斷底層架構」。你自己願意花 9,800 + 買 supastarter，因為你看不懂 code、有想法、討厭重複造輪子——這是高動機的自己。企業主來問，人數你說不多。這比較像早期 adopter，不是已驗證的大眾市場。

「八成只能自己用」我找不到調查數字。行為上確實很多 vibe 成品是自用工具（慢跑追蹤、內部對帳）。自用跟「想賣但賣不出去」是兩群。後者才會付錢。前者可能根本不想商業化，再便宜的金流套件也賣不掉。

▋ 兩個痛點哪一個比較痛

金流／發票／審核：公開討論密度高，金流商自己做 AI Skill，至少三家台灣產品在搶。夠痛。

Landing 不好看：工程圈嫌 AI slop 很兇，但解法是 skill 和參考站，較少人為這件事單獨付高價。比較像金流審核的前置條件（網站要看起來像真的在賣東西），而不是獨立商品。

你後來說要著重「協助他做行銷，接到登入後購買」。這在公開資料裡更接近漏斗問題，比較少人用「行銷」兩個字求救，比較多人卡在「審核要完整網站」。行銷模組有機會，但不宜假設 Threads 上那群人已經意識到「我需要銷售文案」。很多人停在展示功能。

▋ 對 StartKiter 的含義（先當假設）

若主打「接上去就能收錢」，你正面撞 Portaly 和 Recur。他們已經是免費起步或抽成，而且 skill／MCP 體驗跟你要的「跟 AI 講一句話」一樣。買斷 9,800 在這條比較線上會很醜，除非你能講清楚：為什麼不要被抽、為什麼原始碼要在自己手上。

若主打「過金流審核的完整開張路徑」（銷售頁＋條款＋登入＋paywall＋發票＋你的 App 掛上去），這比較沒有單一產品包起來。Portaly 代開發票但抽成高；Recur 不管你的 landing 漂不漂亮；免費 skill 不管商業邏輯和行銷。這才比較像你和 Realms 合起來能贏的洞。

「多租戶」在公開 vibe coder 討論裡幾乎沒出現。他們要的是「別人付了錢就能用」，不是 B2B 組織架構。paywall／會員權限比較貼。organizations 可以當骨架，不要當銷售主張。

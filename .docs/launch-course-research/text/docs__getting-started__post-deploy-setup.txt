PART 1 — LAUNCH · PART 3

部署完成與首次登入

平台跑起來後的第一步：註冊管理員帳號、進入後台、完成初始化設定。

6 min read
第三章：部署完成與管理員設定

上個章節我們已經請 AI 幫我們把整個頁面部署上線了。在過去這可能需要雇用工程師，現在只要交給 AI，大概 20 分鐘左右就能全部幫我們處理好。

這一章，我們要做的事情很簡單：打開管理頁面、註冊第一個管理員帳號，然後一步一步走完系統初始化流程。跑完之後，你的線上課程平台就正式準備好了。

註冊第一位管理員 00:13

部署完成後，點開管理頁面，就可以進到我們的系統裡面。

點擊「立即註冊」
填入你的 Email 與密碼

我們的系統設計是：第一個註冊並進入後台的帳號，會被視為管理員。所以這組帳號密碼請你好好保存，它就是你整個平台的超級管理員。

註冊完成後，系統會自動引導你進到初始化流程。

進入系統初始化流程 00:40

接下來我們會一步一步，根據自己的需求把平台設定好。第一個要決定的，就是「影片要存在哪裡」。

選擇影片儲存方案 00:51

目前我們提供兩種方案，而且這兩種是可以並存的——你某些課程用 YouTube、某些課程用 Cloudflare Stream 都沒問題，決定權完全在你。

YouTube
優點：完全免費，不需要額外的流量費、儲存費
缺點：有外流風險
Cloudflare Stream 01:11

Cloudflare 提供的影音串流服務。

優點：安全可靠、防盜的影音串流與影音託管
缺點：會有費用

如果你今天是極致地想避免課程被外流，我會建議直接使用 Cloudflare Stream。接下來的教學我們會以 Cloudflare Stream 為主，來講怎麼串接它。

費用大致是：

儲存：每 1,000 分鐘影片 $5 美金
播放：每 1,000 分鐘播放 $1 美金

這個費用結構要特別注意一下。

串接 Cloudflare Stream 01:41

我們來實際串一次。先進到 Cloudflare 的頁面登入。

找到 Stream 頁面 01:49

進到後台以後，點擊左上角的 Quick Search，直接搜尋 Stream，選擇第一個結果，就會看到 Stream 的管理介面。

取得 Account ID 01:56

畫面左邊有個 Account details，把那組 Account ID 複製起來，貼回 Onboarding 流程裡。第一個數值就拿到了。

取得 Stream Customer Code 02:11

第二個欄位是 Stream Customer Code，這個稍微特別一點。

在 Cloudflare Stream 頁面裡找到 Customer subdomain，把它複製起來。但貼上時——

我們只需要中間那一段英文就好。從 customer- 減號後面開始，到 .cloudflarestream.com 小數點前面為止，就是中間那一段。

只貼中間那段英文即可，第二個參數就搞定了。

建立 API Token 02:43

第三個參數一樣在 Cloudflare Stream 頁面裡取得。

選擇第三個選項，點擊 Use API
點擊 Get an API token
建立一個新的 API token

建立時有幾個地方一定要注意，特別是 Permissions：

記得新增一條 permission，選擇 Account → Stream → Edit。這三個一定要對上，Account, Stream, Edit 權限必須有。

設定好以後：

按 Continue to summary
點擊藍色的 Create Token

Token 就拿到了。

這個 API token 是私密的，請不要外流給別人。

把它貼回官網的 Onboarding 流程欄位裡，按下一步，我們的影片就可以儲存在 Cloudflare Stream 了。

還是想用 YouTube 也可以 03:43

即使串了 Cloudflare Stream，我們還是可以把影片傳到 YouTube 上面，這倒是沒問題，兩個是兼容的，我自己兩個都有做。

其他初始化項目 03:49
儲存方式

直接選擇「本地儲存」，不需要做任何修改，按下一步。

Email 寄件功能 03:56

如果剛剛我們有請 Codex 幫我們做設定，這邊你應該就會看到寄件功能已經設定完成，不需要再填其他東西、不需要再做任何處理——因為我們剛剛已經請 Codex 幫我們串接好了。

Google 登入 / Apple 登入 04:10

Google 登入與 Apple 登入，我們先跳過，留到其他章節再講解。Onboarding 流程這兩個步驟直接略過沒關係。

完成初始化 04:31

全部設定完以後，點擊「完成初始化」。

完成後，系統會自動把你跳轉回後台管理系統。

恭喜！平台已經上線 04:40

恭喜你，到這邊我們就已經把整個後台管理頁面、把整個線上課程部署起來了。

接下來我們就可以開始進行整個平台的教學講解——怎麼正式上線你的課程內容、怎麼串接金流，一步一步帶你把課程真的賣出去。

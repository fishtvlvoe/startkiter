串接金流開始販售

用 SHOPLINE Payments 讓平台能夠收費 —— 從申請、送審、串接到測試的完整流程。

8 min read
第五章：SHOPLINE PAYMENTS 金流串接
來到最後一步：讓平台真的能收錢 00:00

好，那接下來我們就開始串接 SHOPLINE Payments 吧。

走到這一步你很厲害了 —— 前面我們部署了平台、接好網域、設定完影片串流，現在剩最後這一哩路：讓平台可以真的收到錢。這一章做完，你就能正式上架課程、開始販售。

串接前的準備清單 00:05

在開始串接金流之前，請先幫我確認三件事：

課程已經準備好了：你至少要有一門準備好要販售的課程，而且價格已經定下來。
隱私權政策已經寫好：這是送審會檢查的項目之一。
服務條款已經寫好：同樣是送審必備。

為什麼要先準備好這些？ 因為 SHOPLINE Payments 在審核時會實際去看你的網站，確認你是真的在做生意、有合規的條款。如果網站還是空的，審核會被退件。

都準備好以後，幫我進到系統設定 → 金流設定，然後選擇 SHOPLINE Payments。

第一步：註冊 SHOPLINE Payments 帳號 00:25

我們可以先直接登入到 SHOPLINE Payments 的後台，在這裡註冊一個新的帳號。

註冊完成以後，你會看到一個「開通 SHOPLINE Payments」的藍色按鈕，直接點下去就會進入開通流程。

第二步：填寫開通資料 00:36

進來以後，順著自己的情況一路填寫就好。大致會問你這些：

身分證字號 00:47
經營資訊
每月預估營業額 00:51
經營的商店資訊

在「商店類型」這個選項，我們直接選 「服務 / 課程」，分類就填「課程類」 01:00。

商店交易名稱 —— 這裡要特別認真填 01:06

這一欄很重要。商店交易名稱會顯示在客戶的信用卡帳單上，所以我很建議你要認真去填。

為什麼要認真填？ 如果這個名稱客戶看不懂，可能會申請拒付。

舉個實例：有些人習慣每個月去對信用卡帳單，看到一筆帳單名稱他真的認不出來，就直接去申請拒付。事實上他只是忘了這筆是來自他買的線上課程而已 —— 但對你來說就是一筆被退款的訂單。所以這個名稱一定要讓客戶一眼就認得出來。

商店的其他資訊
商店名稱：順著填就好。
商店網址：直接貼你線上課程平台的網址 01:45。
銀行帳戶
總覽確認
第三步：提交審核，等三到五天 01:59

全部填寫完以後就可以提交審核。

送審時間：大概 三到五天 後審核結果就會出來。這段期間你可以先去準備其他東西 —— 錄課程、調整平台文案、寫行銷素材。

收到審核通過通知後，我們就可以進到 SHOPLINE Payments 後台，看到整個後台總覽，然後繼續把線上課程平台和 SHOPLINE Payments 串接起來。

第四步：取得 Merchant ID 02:22

首先幫我進到 SHOPLINE Payments 後台的 設定 裡面來。

這裡會有一個 Merchant ID，請幫我把這個 Merchant ID 複製起來，直接貼到線上課程平台的：

系統設定 → 金流設定 → 商店代號

直接貼上就好。

第五步：取得 API Key 02:36

第二個要拿的是 API Key。請幫我在 SHOPLINE Payments 後台選擇 開發者管理，這裡會有一個「查看詳情」，點進去。

進去後你可以：

新增金鑰，或
直接複製既有的 API Key

把 API Key 複製起來，貼到線上課程平台的 API Key 欄位即可。

第六步：建立 Webhook 02:58

接下來我們要創建 Webhook。幫我點擊 Webhook 管理，然後新增 Webhook。

我們可以在線上課程平台的系統後台這邊看到 Webhook URL（也就是 Notify URL / Return URL 的接收端點），把它複製起來，貼到 SHOPLINE Payments 的 URL 欄位。

小提醒：貼過去以後記得檢查一下開頭，前面多餘的部分要刪掉，不然 Webhook 會失效。

接著：

Webhook 名字：簡單寫 Default 就好，這只是讓自己辨認用的。
訂閱事件：直接點擊 全選 03:15。
Sign Key：暫時不填，直接按完成。

完成以後 SHOPLINE Payments 會產生一組 Sign Key 給你 —— 把這組 Sign Key 複製起來，貼到線上課程平台的 Sign Key 欄位 03:46。

第七步：對齊每個欄位 03:54

這樣我們每個參數就填寫完了。再幫你確認一次對應關係：

線上課程平台欄位	來源位置（SHOPLINE Payments）
商店代號（MerchantID）	設定頁面的 Merchant ID
API Key	開發者管理 → 金鑰管理
Sign Key	Webhook 管理建立後產生的 Sign Key

全部都處理完以後，直接按 儲存設定。

第八步：測試連線 04:12

存完以後，按 測試連結 看看。

如果一切正確，它會直接顯示：成功連線。

測試模式 vs 正式模式：我剛剛測試時是用沙盒模式。如果你今天是要正式上線收錢，記得把沙盒模式關閉，不然客戶是刷不過的。 04:18

完成！你可以開始賣課了 04:24

到了這邊，金流設定就算串接完成了。

你現在可以正式銷售你的課程了。

恭喜你走完 Series 1

如果你是一路跟著這五章走下來，從最開始的平台介紹、部署、串接網域、影片串流，一路到現在這一章完成金流 —— 你已經擁有了一個完整可以運作、可以收費的線上課程平台。

這不是玩具版、不是 demo，是一個可以真的賣課的平台。

接下來可以做什麼？
上架你的第一堂課：把課程內容、章節、影片都上傳好。
跑一次真實購買流程：用沙盒模式或小額測試，自己走一次完整的結帳流程，確認整條鏈路沒問題。
分享你的課程網址：開始行銷、開始賣、開始收錢。
繼續往下學 Vibe Coding：如果你想把平台微調成更符合你品牌的樣子，後面的系列會教你怎麼用 AI 去改這個平台。

辛苦了。從零到能收錢，你做到了。

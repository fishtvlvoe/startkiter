課 + 終身代碼包，長成一個類似 WordPress 的可擴充平台，不是單一固定功能清單的 SaaS。買家一次買斷拿到一個殼（platform shell）＋可掛載模組（plugin）的架構，外加台灣金流、課程系統、站內教學。這頁是固定網址的專案儀表板，每次工作完會更新這裡，不用重新對焦。

對焦：我理解的目標

四句話講完在賣什麼、長什麼架構、怎麼教、現行邊界

賣什麼

對外課名「開站包」。買家一次買斷（PAYUNi・TWD 8800），拿到一套自己的平台 ＋ 台灣金流模組 ＋ 課程系統，可以自己改、自己上線。

長什麼架構

類似 WordPress：殼 + 可掛載模組。後台掛載點、Marketplace 展示頁、模組各自獨立 packages/，對應 platform-shell-plugin-architecture 這張施工單，是產品第一性。

怎麼教

站內留一個只讀兩工具的 AI agent、內建課程模組講解怎麼改代碼、LINE 社群互相支援、GitHub Kit 交付原始碼讓買家自己接手開發。

現行邊界

以 openspec/specs/ 為準。THE-TU 全套內容/金流/行銷模組已開放抽取當核心模組——抽取來源以 woomin repo 為主、thetu 為輔；登入機制維持 Better Auth，不抽 NextAuth。

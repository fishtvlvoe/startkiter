工具：`ego-browser nodejs`，task space `18`
環境：`http://localhost:3001`；測試用 local S3-compatible fixture `http://127.0.0.1:9000`；未使用 Playwright、Chrome MCP 或其他瀏覽器自動化。

## 實際流程與結果

1. 以 `assignment-operator-e2e-20260824@example.com` 登入，進入 `/admin/course`，選擇 `講師範圍 E2E 課程` 的 `浮水印 E2E 單元`。
2. 在 `MediaPicker` 登記 Bunny URL：
   `https://iframe.mediadelivery.net/play/123456/course-media-e2e-20260825`
   頁面顯示 `影片已登記到媒體庫。`，provider 顯示 `BUNNY`；點擊「發布變更」後頁面顯示 `單元變更已成功持久化至 PostgreSQL 資料庫`。
3. 進入 `/course/cmt779upr0003uuz7y5qqsxzo`，`[data-testid="player-frame"] iframe` 實際存在，src 為：
   `https://iframe.mediadelivery.net/play/123456/course-media-e2e-20260825`
   頁面同時顯示課程播放器、單元標題、浮水印資訊與「影片全螢幕」按鈕。
4. 回到課程設定，用 `MediaPicker` 選取 `course-site-dark.png`，透過 signed URL PUT 至 local S3 fixture，再完成媒體登記。頁面顯示 `圖片已上傳並登記到媒體庫。`，引用顯示 `COURSE_COVER / cmt753aqz0000vkz7ro9to7el`。
5. 以暫時的 E2E paid entitlement 開啟 `/course`，前台 `[data-testid="course-cover-image"]` 實際存在，src 為 `/image-proxy/media/...png`，alt 為 `課程封面`。
6. 開啟 `/admin/media`，實際看到 Bunny 影片、課程封面圖片，以及既有回填影片；Bunny 影片顯示 `VIDEO · provider：BUNNY` 與 `LESSON_CONTENT / cmt779upr0003uuz7y5qqsxzo`，圖片顯示 `IMAGE` 與 `COURSE_COVER / cmt753aqz0000vkz7ro9to7el`。
7. 媒體庫四筆使用中媒體的刪除按鈕實際檢查結果皆為 `disabled: true`，文字為 `使用中，無法刪除`。

## 這輪交付

同一個本機入口，三種角色分清楚：平台管理員管理示範使用者／模組；創作者管理商品與營運；買家查看自己取得的內容。後台是上方主分類、左側子選單、右側內容，不再省略左側這層。

商品新增、編輯、收費設定、本機保存、重新整理回填與買家模擬取得必須能操作。設定、網站／郵件／自動化／銷售等尚未串接區域明確標示為介面提案；不假報已保存、已扣款、已寄信或已開播。這輪不是正式上線。

## 工作流程

1. Fish確認這張SR及分工。
2. 主控固定共用選單、樣式、view介面與資料命令，保留既有操作版可用。
3. 三個worker同時做各自角色頁；每個先測試再實作，只修改自己的檔案。
4. 主控接回同一入口，集中驗證桌面／手機及新增→保存→重整→編輯→取得流程。
5. 開給Fish驗收；Git提交／推送另按scoped plan核准，正式功能後續交各自原SR。

### 第 4 頁：核心架構：一行 `<script>` 搞定全端雲服務
- **版面型態**：4 宮格能力矩陣圖
- **標題**：不用架伺服器！一行引入四大雲端超能力
- **引入代碼**：`<script src="https://js.puter.com/v2/"></script>`
- **4 大能力**：
  1. **Auth 認證**：免寫登入、Session、密碼重設，首次存取自動呼叫授權彈窗。
  2. **KV 雲端資料庫**：`puter.kv.set / get`，自動綁定使用者雲端空間。
  3. **AI Gateway**：`puter.ai.chat` 原生聚合 500+ 款頂尖大模型。
  4. **Cloud Storage**：`puter.fs.write / read` 雲端檔案儲存。

### 第 5 頁：秘密武器：為什麼 AI 寫 Puter 程式碼從不翻車？
- **版面型態**：左側代碼架構 / 右側 3 大效能指標
- **標題**：專為 AI Coding 設計的 API 藍圖 —— `llms.txt`
- **重點內容**：
  - **單頁 SSOT**：`docs.puter.com/llms.txt` 將完整 API 精簡為 LLM 專用格式。
  - **零配置中斷**：無 Connection String、無環境變數，Cursor/Claude 一次生成不卡頓。
  - **數據優勢**：Token 消耗降低 90%，程式碼行數減少 12 倍（相比 Supabase/AWS）。

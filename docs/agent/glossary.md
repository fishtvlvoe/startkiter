# StartKiter Creator Platform Glossary

| Term | Canonical meaning | Do not confuse with |
| --- | --- | --- |
| Creator Workspace | 一個創作者或團隊的資料、設定、權限與營運範圍；第一版以 Organization 為持久化邊界 | User account、App |
| User | 可登入平台的身份 | Contact、Subscriber |
| Contact | 創作者可經營的關係資料，可尚未註冊 | User |
| Audience | 依條件選出的 Contact 集合 | Contact table |
| Consent | 特定目的、來源、版本、時間的同意或撤回證據 | Login identity |
| Content | 可被觀看、下載或使用的內容資源 | Product、Offer |
| Product | 可被販售的商品聚合 | Course、Page |
| Offer | 商品的價格、付款模式、交付與促銷條件 | Product |
| Entitlement | 付款或授權後可使用的資格 | Order |
| Campaign | 手動或排程發送的一次訊息活動 | Automation |
| Automation | 由事件觸發、可重試的規則流程 | Campaign |
| Provider adapter | 將外部服務轉成 StartKiter 的穩定介面 | Domain rule |
| 工作台 | 以今天任務與結果為中心的首頁 | 全功能側欄 |

同一個引擎，能長出不同學習世界。

以下是用來對焦的課程案例，不是固定模板。老師保留自己的專業判斷，課神負責把它建模成可操作、可回饋、可驗收的學習路線。

案例 01 / 顧問訓練

案神：從一段對談找出真正需求

學員面對一段充滿雜訊的訪談，必須追問、標記證據，再決定下一個最值得問的問題。

老師放進去
訪談素材、判斷準則、常見誤區與專業回饋。
學生帶走
一份有證據鏈的需求拆解，不只是看完一支影片。
案例 02 / AI SaaS 實戰

從想法到第一個可測試版本

學員選定一個華語市場問題，走過訪談、定位、頁面驗證與第一次失敗，再修正下一步。

老師放進去
自己的決策框架、案例資料、檢核表與真實限制。
學生帶走
一個能展示的驗證包，知道為什麼改、下一步要找誰驗證。
案例 03 / 教練陪跑

把一次諮詢變成一段可持續的改變

學員不是勾完清單就結束，而是在每週任務中做選擇、收到回饋，慢慢形成自己的習慣。

老師放進去
診斷問題、分級任務、鼓勵語氣與需要人工介入的邊界。
學生帶走
每週一個小成果，感覺自己真的在前進，而不是被課程推著走。

同一套系統，老師和學生得到的是兩種不同的自由。

老師不必再把所有時間花在剪片、串頁面、想題目；學生也不必再把學習等同於看完進度。課神把兩邊都拉回真正重要的事：做出判斷，留下證據。

站在老師角度

把專業變成可玩的系統
  • 更快把想法變成原型用一句話描述能力與情境，AI 先組出任務骨架，老師再做專業裁決。
  • 保留自己的教學個性引擎不替老師決定要不要用影片、分支、對話或遊戲規則。
  • 在部署前先親自試玩用學員身分走過流程，提早發現卡住的地方，降低粗製濫造的風險。
  • 一套模型，重組成多堂課同一組工具與判定可以換案例、換難度、換產業，不必每次從零開始。
  • 專業價值不再只靠名氣學員看到的是你的判斷如何造成結果，而不是只有包裝好的投影片。

站在學生角度

把看懂變成做過
  • 我可以做有意義的選擇不是一路按下一頁，而是要決定、承擔後果，再看系統怎麼回應。
  • 失敗不等於被淘汰提示、復原與重試保留控制權，讓困難變成下一次判斷的材料。
  • 回饋說明為什麼系統指出哪個證據不足、哪個條件被忽略，而不是只顯示對或錯。
  • 完成後留下能力證據作品、決策紀錄與修正歷程能被展示，也能回頭重跑。
  • 學完知道下一步每個任務都接到真實情境，學習不會停在課程結束的那一刻。

課神的核心價值 對老師：把「我會教」變成「學員真的做得到」 對學生：把「我看過」變成「我做過，而且知道為什麼」

學生端不是 LMS 加動畫。

畫面會動不代表學會。Learning Feel 來自學員能做選擇、承受阻力、理解回饋、留下成果，失敗時仍拿得回控制。

主動感我能做有意義的選擇。
阻力感困難來自真實約束，不是拖時間。
回饋感我知道剛才發生了什麼。
結果感完成後留下作品與能力證據。
被接住可以失敗、復原與求助，但答案不被奪走。

AFC Loop 是最小驗收單位

Action學員採取可觀察的行動，不只是按下一頁。
Feedback系統解釋行動如何被判定，以及哪個邊界改變。
Consequence結果改變下一步，並留下可重跑、可展示的證據。

Recovery：沒有通過時，階梯式提示先指出範圍，再把控制權交回學員。

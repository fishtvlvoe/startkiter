StartKiter 的環境變數範例來自 `apps/saas/.env.example`。請複製一份給自己的本機或部署環境使用；不要把真實金鑰、密碼或私鑰放進 Git。

## 怎麼看必填／選填

本頁列出範例檔中的全部 88 個變數。`必填` 表示應用程式基本啟動沒有安全預設值；`選填` 表示有預設值、空值會安全降級，或只在對應功能啟用時需要。標成選填的功能一旦啟用，仍要填完整的一組設定。

## 基本執行環境

| 變數 | 必填／選填 | 用途 |
| --- | --- | --- |
| `DATABASE_URL` | 必填 | PostgreSQL 資料庫連線。 |
| `BETTER_AUTH_SECRET` | 必填 | Better Auth session 與簽章密鑰。 |
| `BETTER_AUTH_URL` | 必填 | 結帳與對外 origin。缺少時結帳路徑會 fail closed。正式環境請填實際網址。 |
| `NEXT_PUBLIC_SAAS_URL` | 選填 | Better Auth `baseURL` 與應用程式公開網址；未填時本機會落到 localhost。正式環境請填實際網址。 |
| `NEXT_PUBLIC_MARKETING_URL` | 選填 | 行銷站公開網址。 |
| `NEXT_PUBLIC_DOCS_URL` | 選填 | 文件站公開網址。 |
| `NEXT_PUBLIC_VERCEL_URL` | 選填 | 舊部署環境相容用的公開網址。 |
| `ADMIN_EMAIL` | 選填 | Operator 電子郵件；空白時不授予任何人 operator 權限。 |
| `SETTINGS_ENCRYPTION_KEY` | 選填 | 加密資料庫設定；要從後台寫入 PAYUNi 或電子發票設定時必填。 |

| `EINVOICE_PROVIDER` | 選填 | 電子發票 provider，範例預設為 ezPay。 |
| `EINVOICE_MERCHANT_ID` | 選填 | 電子發票商家代號；啟用開票時必填。 |
| `EINVOICE_HASH_KEY` | 選填 | 電子發票驗證金鑰；啟用開票時必填。 |
| `EINVOICE_HASH_IV` | 選填 | 電子發票驗證向量；啟用開票時必填。 |
| `EINVOICE_TEST_MODE` | 選填 | 電子發票測試模式，範例預設為 true。 |
| `EINVOICE_ENABLED` | 選填 | 是否啟用電子發票，範例預設為 false。 |

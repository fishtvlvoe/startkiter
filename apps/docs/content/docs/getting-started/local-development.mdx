本頁只整理倉庫既有的開發啟動方式。請在倉庫根目錄執行指令，並先準備好自己的環境變數檔。下列指令對應根目錄 `package.json` 的既有 scripts，不是新的啟動流程。

## 安裝相依套件

```bash
pnpm install
```

第一次安裝會依照 lockfile 準備所有 workspace 套件。不要把含有真實金鑰的環境變數檔提交到 Git。

## 啟動開發環境

```bash
pnpm dev
```

根目錄的開發指令會啟動 monorepo 內的應用程式。需要只看文件站時，可以改用文件站 package 的開發指令，在 3002 port 啟動。

## 啟動前檢查

1. `DATABASE_URL`、`BETTER_AUTH_SECRET`、`BETTER_AUTH_URL` 已填入本機環境。
2. 需要結帳時，確認 PAYUNi 設定已由後台或 fallback 環境變數提供；缺少金鑰時結帳會 fail closed。
3. 需要其他整合時，只填入該功能使用的設定，未啟用的 provider 可以保持空白。

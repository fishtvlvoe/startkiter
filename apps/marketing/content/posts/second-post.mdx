People should not need to decode a pricing table to understand a one-time purchase. Start with the amount, then name the course and the code delivery. The decision becomes easier when the offer matches the checkout.

StartKiter presents one offer: NT$8,800 for the course and lifetime GitHub code package. The platform shell is part of the code delivery, with room for modules as the site grows.

That order keeps the marketing page and checkout aligned: amount first, then what the buyer gets, then the next action. There is no second plan to compare and no recurring fee to explain.

### A clear next step

When the offer is clear, the next step can stay simple: review the course scope, purchase the package, and follow the delivery flow to access the course and code.

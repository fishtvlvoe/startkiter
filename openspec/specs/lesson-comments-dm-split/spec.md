# lesson-comments-dm-split Specification

## Purpose

把「課程留言」（公開討論）與「學員私訊老師」（一對一）拆成兩個獨立的前後台入口，避免現在混在同一個面板裡讓學員分不清楚訊息是公開還是私下的，也讓講師能像用聊天軟體一樣管理私訊。

## Requirements

### Requirement: 前台留言與私訊分離入口

學員在課程播放頁能清楚分辨「留言（其他學員看得到）」跟「私訊老師（只有老師看得到）」是兩個不同功能，不會誤送錯管道。

#### Scenario: 學員在播放頁選擇私訊老師

- **WHEN** 學員在課程播放頁點擊「私訊老師」
- **THEN** 開啟獨立的私訊輸入介面，訊息寫入 `LessonPrivateMessage`，不會出現在公開留言區 `LessonComment` 底下

### Requirement: 後台私訊 Messenger 式介面

講師/管理員在後台管理私訊時，能像聊天軟體一樣看到所有對話串列表、未讀狀態、並在同一畫面直接回覆。

#### Scenario: 講師查看未讀私訊

- **GIVEN** 有 3 位學員各發了 1 則新私訊，講師尚未讀取
- **WHEN** 講師打開後台「學員私訊」頁
- **THEN** 左側對話清單顯示 3 筆未讀紅點，點擊任一對話可在右側直接輸入回覆並送出，不需跳轉其他頁面

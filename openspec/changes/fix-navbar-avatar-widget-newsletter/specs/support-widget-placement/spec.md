## Purpose

客服按鈕現在固定卡在右下角，不能收合也不能移開，會擋住畫面內容。這份要讓它能收起來，功能不變。

## ADDED Requirements

### Requirement: 客服按鈕可收合

`SupportWidget.tsx` 從固定不可動的按鈕，改成可收合/可關閉，收合後不佔用畫面內容空間。

#### Scenario: 使用者收合客服按鈕

- **GIVEN** 客服按鈕目前展開中，擋住畫面內容
- **WHEN** 使用者點擊收合
- **THEN** 按鈕縮小成不擋內容的小圖示，原本的 `handleOpenChat` 點擊開啟客服功能維持可用

#### Scenario: 收合狀態記住不會每次重新展開

- **GIVEN** 使用者上次瀏覽時把客服按鈕收合了
- **WHEN** 使用者重新整理頁面
- **THEN** 客服按鈕維持收合狀態，不會每次都彈回展開
